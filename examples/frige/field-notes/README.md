# Field Notes

This synthetic book demonstrates Frige's manuscript layout and reading order.
[Programme](manuscript/Programme.md) links the sources in print order.

In an authorized local checkout, copy the `field-notes` directory into a
disposable books directory. Set `STEX_FRIGE_BOOKS_DIR` to that parent
directory before starting the stack. Choose **Field Notes** in Frige to
open it, then select **Typeset proof** to compile the example.
