# Woden

Woden is the STEX Pantheon application for manuscripts, story structure and review
workflows. It owns revisions, workflow state and accepted story-graph records.
The vault can contain related research and human-readable links, never a
second authoritative manuscript store.

No implementation has been imported yet. The first feature is a local,
single-user project with explicit revision authority.

The [platform transition](../../docs/PLATFORM-TRANSITION.md) concentrates on
Frige, Seaxneat and Igor. This domain remains deferred; future presentation
belongs in Pantheon with engine-owned narrative state, not another complete shell.
