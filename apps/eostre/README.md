# Eostre

Eostre is the STEX Pantheon application for visual work, image lineage and print
production. It owns its project graph, artwork revisions and deterministic
print operations. Vault notes may describe references and decisions, but they
do not replace these records.

No implementation has been imported yet. Add only the first local user path
after its application-state contract and failure behavior are specified.

The [platform transition](../../docs/PLATFORM-TRANSITION.md) concentrates on
Frige, Seaxneat and Igor. This domain remains deferred; future presentation
belongs in Pantheon with engine-owned artwork state, not another complete shell.
