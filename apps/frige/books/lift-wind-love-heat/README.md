# Lift Wind/Love Heat

*Lift Wind/Love Heat: Symphony No. 1 in C Minor* is a creative poetry manuscript.

## Project layout

- `manuscript/` — the sectioned working manuscript, front matter, back matter, and programme.
- `compiled/` — the existing single-file compilation.
- `notes/` — project-specific editorial or interpretive notes.

The sectioned manuscript and the compiled file are preserved as separate artifacts; do not assume either updates the other automatically. Reconcile them deliberately when revising.

This is book work, not an article package. Preserve the manuscript's existing sequence and do not introduce newsletter templates, claim ledgers, or publication packets.

For revision gates, use `composition_workshop/MANUSCRIPT_WORKFLOW.md` alongside this project's instructions.
