# STEX Pantheon

STEX Pantheon is a local-first workspace for creative production. Frige
manages manuscripts and proofs, Seaxneat manages website projects and
revisions, and Igor provides project-aware conversations where configured.

The curated GitHub release is a **source-reading edition**. It contains suite
source, tests, contracts, development tooling, documentation and a synthetic
Frige example. The integrated stack requires an authorized checkout of the
private Igor repository and Git LFS media.
