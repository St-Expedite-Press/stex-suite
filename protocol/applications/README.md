# STEX application registry v1

`registry.v1.json` defines the identities that the local STEX shell may show.
It is a public navigation contract, not a shared database or authorization
mechanism. The `stex://` forms are `stex://<id>/<reference-kind>/<id>`; the
owning application alone resolves and authorizes them.

In Pantheon Alpha A0, Frige and Seaxneat are active. Eostre and Woden are
registered deferred identities only.
