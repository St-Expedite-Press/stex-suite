# Source and asset rights

The GitHub release is prepared as a source-reading archive. The release
manifest identifies the exact files under review. Release terms will be
recorded with the approved download.

| Material | Evidence and clearance |
| --- | --- |
| STEX software and documentation | Software distribution terms require owner approval. |
| Synthetic Frige example | A purpose-written example accompanies the source. |
| Tracked manuscript | Separate author clearance is required for inclusion. |
| Brand masters and references | See the [asset book](../assets/README.md) for provenance. Inclusion requires separate approval. |
| Distributed media | Each included derivative must be cleared for distribution. |
| Bundled fonts and icons | See [third-party notices](../THIRD-PARTY-NOTICES.md). |

The release archive and the existing repository history have different
contents. Consult the release manifest for the contents of a specific
download.
