# STEX design system

The implemented system uses warm paper surfaces, charcoal navigation, Georgia editorial headings, system sans text, moss-green action controls, and ochre or rust production accents. Frige supplies the reference workstation language; Seaxneat adapts it into a project-list/sidebar layout.

The Lab shell adds an implemented print motif: living palette variables, halftone field, grain, crop marks, registration targets, and animated misregistration. Motion respects reduced-motion preferences. No unimplemented Art Nouveau, Celtic, cybernetic, or generated asset system is claimed here.
