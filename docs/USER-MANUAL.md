# STEX user manual

Run `corepack pnpm install --frozen-lockfile`, then `corepack pnpm dev:alpha`. Open `http://127.0.0.1:4300/`.

## Frige

Choose **Frige** on the suite page. Select an existing local book or create a new scaffold. A book opens only after explicit selection. Edit a source node, save it, typeset a proof, inspect the PDF and preflight, and review any fake-Hermes proposal before accepting it. Do not use a protected manuscript as a test fixture.

## Seaxneat

Choose **Seaxneat**, create a local project, wait for its validated Next.js build, then start the preview. Request a bounded heading edit, inspect it, apply it explicitly, view a revision diff, and restore a validated revision when needed. State is local and the vault is disabled by default.

Eostre and Woden deliberately show deferred views in A0.
